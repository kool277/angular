# Coverage

Every page of the official Angular docs for this version under `introduction/essentials/` and
`guide/` (from `adev/src/content/` at v22.2.6, 156 pages) and the chapter of this guide
that explains it. Each chapter links to its pages in part 10, "Read more".

Left out: none. Some pages get only a short section and a link, because they are reference
material or describe tools for a later stage:

- the Angular Aria widget pages (chapter 22 builds tabs, an accordion and a listbox, and links the
  others);
- the older `@angular/animations` pages (chapter 23 explains them as older code);
- `guide/drag-drop`, which is part of the Angular CDK, built outside this repository
  (chapter 27);
- `guide/testing/component-harnesses-testing-environments`, `guide/testing/karma` and
  `guide/testing/zone-js-testing-utilities`, which matter for library authors and older
  projects (chapter 19).

Chapters 02, 03, 18 and 26 cover topics whose official pages live outside `guide/` (the CLI,
TypeScript, RxJS interop, building and updating); they link to those pages.
